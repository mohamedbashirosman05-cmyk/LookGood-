5Das muss neu gebaut werden, damit es eine echte App wird

Du willst eine App wie Snapchat: Du schickst ein Update, und alle behalten ihr Konto, ihre Kleidung, ihre Freunde und ihr Abo. Dafür fehlt heute das Wichtigste:

  • Heute liegt alles nur auf dem Handy (im Browser-Speicher). Neues Handy, App gelöscht oder Browser-Daten gelöscht: alles weg.
  • Echte Konten und Datenbank: Konten, Kleidung, Fotos, Looks, Freunde und Abos müssen auf einem Server liegen. Die App zeigt sie nur an. Dann ersetzt ein Update nur den App-Code, und die Daten bleiben.
  • Echte Anmeldung: echte SMS- und E-Mail-Codes, echtes „Mit Apple / Google anmelden“.
  • App Store / Play Store: Die HTML wird in eine richtige App verpackt. Updates laufen dann über die Stores.
  • Ordnung im Code: Statt einer riesigen Datei ein sauberes Projekt mit Versionen. So kann jeder Fehler gezielt repariert werden.
  • Fehler melden: ein Knopf in der App, mit dem Nutzer Fehler schicken können.

Wichtig: Die HTML-Datei ist unser Prototyp, also das Modell, an dem wir das Aussehen und die Abläufe festlegen. Die echte App baut später darauf auf.
